# 🚀 Быстрый запуск приложения

## После перезагрузки компьютера

### Самый простой способ:

**Двойной клик по файлу `start-all.bat`**

Это автоматически:
- ✅ Проверит, не занят ли порт 8000
- ✅ Запустит сервер в отдельном окне
- ✅ Запустит клиент в текущем окне
- ✅ Откроет приложение в браузере

### Что делать, если появилась ошибка "ECONNREFUSED"?

1. **Проверьте, запущен ли сервер:**
   - Должно быть открыто окно с текстом "Сервер запущен на порту 8000"
   - Если окна нет, запустите `start-server.bat`

2. **Если порт занят:**
   - Закройте все окна с сервером
   - Подождите 5 секунд
   - Запустите `start-all.bat` снова

3. **Если ничего не помогает:**
   - Откройте PowerShell в папке проекта
   - Выполните: `.\start-all.ps1`
   - Это покажет подробную информацию об ошибках

## Альтернативные способы запуска

### Только сервер:
Двойной клик по `start-server.bat`

### Только клиент (если сервер уже запущен):
Двойной клик по `start-client.bat`

### Через командную строку:

**Терминал 1:**
```bash
npm start
```

**Терминал 2:**
```bash
npm run client
```

## Настройка автозапуска при входе в Windows

1. Нажмите `Win + R`
2. Введите: `shell:startup`
3. Создайте ярлык для `start-all.bat` в этой папке
4. При каждом входе в Windows приложение будет запускаться автоматически

## Проверка работы

После запуска откройте в браузере:
- **Клиент:** http://localhost:3000
- **Сервер API:** http://localhost:8000/api/groups

Если страницы открываются без ошибок - всё работает! ✅

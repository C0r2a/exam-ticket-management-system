# 🎓 Система управления экзаменационными билетами

Веб-приложение для автоматизированного создания, распределения и отслеживания экзаменационных билетов в учебных заведениях.

## ✨ Возможности

### Для администратора:
- ✅ Управление пользователями (создание, редактирование, удаление)
- ✅ Управление учебными группами (создание, редактирование, удаление)
- ✅ Просмотр логинов и паролей всех пользователей
- ✅ Назначение курсантов к учебным группам
- ✅ Назначение дисциплин к учебным группам

### Для преподавателя:
- ✅ **Мастер настройки** с пошаговым процессом подготовки экзамена
- ✅ Создание дисциплины и учебной группы через мастер настройки
- ✅ Загрузка вопросов из TXT-файла (один вопрос на строку, автоматическая нумерация)
- ✅ Импорт курсантов из TXT-файла (одно ФИО на строку)
- ✅ Автоматическая генерация логинов и паролей для курсантов
- ✅ Настройка параметров билетов:
  - Количество билетов (1-100)
  - Количество теоретических вопросов (1-20)
  - Практические задания (опционально, 1-100 заданий)
  - Разделы вопросов (опционально, с указанием границы между разделами)
- ✅ Генерация билетов с уникальными комбинациями вопросов
- ✅ Выбор курсанта для выбора билета
- ✅ Статистика выбора билетов с полным списком вопросов и временем получения
- ✅ Сброс всех данных на любом этапе настройки

### Для курсанта:
- ✅ Выбор билета из доступных
- ✅ Просмотр доступных билетов в виде интерактивных карточек
- ✅ Модальное окно с подробным отображением билета:
  - Номера вопросов из файла
  - Полный текст всех вопросов
  - Практические задания (если настроены)
- ✅ Автоматическое блокирование выбора после получения билета
- ✅ Просмотр статистики после завершения выбора всеми курсантами

## 🛠 Технологии

- **Backend**: Node.js, Express, SQLite, Multer (для загрузки файлов)
- **Frontend**: React
- **Стилизация**: CSS3 с космической темой, градиентами и анимациями
- **Шрифты**: Montserrat (для текста) и Magistral (для заголовков) - локальные

## 📦 Установка и запуск

### 1. Установка зависимостей

```bash
# Установить зависимости для сервера и клиента
npm run install-all
```

Или по отдельности:

```bash
# Установить зависимости сервера
npm install

# Установить зависимости клиента
cd client
npm install
cd ..
```

### 2. Запуск приложения

#### Быстрый запуск (рекомендуется)

**Windows:** Двойной клик по файлу `scripts/start-all.bat` - запустит сервер и клиент автоматически.

**PowerShell:**
```powershell
.\scripts\start-all.ps1
```

#### Ручной запуск

Откройте два терминала:

**Терминал 1 (Backend):**
```bash
npm start
# или с автоперезагрузкой:
npm run dev
```

**Терминал 2 (Frontend):**
```bash
npm run client
```

Приложение будет доступно на `http://localhost:3000`

**Важно:** Сервер работает на порту `8000`, клиент на порту `3000`.

#### Другие скрипты запуска

Все скрипты находятся в папке `scripts/`:
- **`scripts/start-server.bat`** - запускает только сервер
- **`scripts/start-client.bat`** - запускает только клиент
- **`scripts/start-all.bat`** - запускает сервер и клиент одновременно
- **`scripts/prepare-offline.bat`** - подготовка проекта для автономного развертывания

## 🚀 Использование

### Сценарий 1: Настройка системы (администратор)

1. Войдите в систему под учетной записью администратора
2. Создайте учебные группы через вкладку **"Учебные группы"**
3. Создайте пользователей (преподавателей и курсантов) через вкладку **"Пользователи"**
4. Назначьте курсантов к соответствующим учебным группам
5. Назначьте дисциплины к учебным группам

### Сценарий 2: Подготовка экзамена (преподаватель)

1. Откройте приложение и перейдите в режим **"Настройка"**
2. **Шаг 1: Ввод данных дисциплины**
   - Введите название дисциплины
   - Выберите тип (Экзамен/Зачет)
3. **Шаг 2: Загрузка вопросов**
   - Загрузите TXT файл с вопросами (один вопрос на строку)
   - Вопросы автоматически получат номера по порядку в файле
4. **Шаг 3: Ввод данных группы**
   - Введите название учебной группы
5. **Шаг 4: Добавление курсантов**
   - Добавьте курсантов вручную (ФИО) или импортируйте из TXT файла
   - Логины и пароли генерируются автоматически
6. **Шаг 5: Конфигурация билетов**
   - Установите количество билетов (1-100)
   - Установите количество теоретических вопросов (1-20)
   - При необходимости включите практические задания (1-100)
   - При необходимости включите разделы вопросов (укажите границу n)
7. **Шаг 6: Генерация билетов**
   - Нажмите **"Сгенерировать билеты"**
   - Дождитесь завершения генерации
8. **Шаг 7: Готово**
   - Проверьте информацию и нажмите **"Начать экзамен"**

### Сценарий 3: Сдача экзамена (курсант)

1. Переключитесь в режим **"Сдача"** (или откройте приложение, если настройка завершена)
2. Выберите курсанта из выпадающего списка
3. Выберите билет из доступных карточек
4. В модальном окне отображается:
   - Все вопросы билета с их номерами
   - Практическое задание (если настроено)
5. Нажмите **"Начать подготовку"**

## 📄 Формат файлов

### Файл с вопросами

Создайте TXT файл, где каждый вопрос находится на отдельной строке. Вопросы автоматически получат номера по порядку в файле (1, 2, 3...):

```
Что такое переменная?
Как объявить функцию?
Что такое массив?
```

### Файл с курсантами

Создайте TXT файл, где каждое ФИО находится на отдельной строке:

```
Иванов Иван Иванович
Петров Петр Петрович
Сидоров Сидор Сидорович
```

## 🔧 API Endpoints

### Вопросы
- `GET /api/questions` - получить все вопросы
- `POST /api/questions/upload` - загрузить вопросы из файла

### Конфигурация
- `POST /api/config` - сохранить конфигурацию

### Билеты
- `GET /api/tickets/available-simple` - получить доступные билеты
- `POST /api/tickets/generate` - сгенерировать билеты
- `POST /api/tickets/:ticketId/select-simple` - выбрать билет
- `GET /api/tickets/statistics` - получить статистику

### Пользователи и группы
- `GET /api/groups` - получить все группы
- `POST /api/groups` - создать группу
- `GET /api/groups/:groupId/students` - получить курсантов группы
- `POST /api/users/import` - импортировать курсантов из файла

## 🎯 Особенности

- **Автономная работа**: система не требует подключения к интернету
- **Локальные шрифты**: все шрифты включены в проект
- **SQLite база данных**: не требует отдельной установки СУБД
- **Простое развертывание**: можно развернуть на любом компьютере с Node.js

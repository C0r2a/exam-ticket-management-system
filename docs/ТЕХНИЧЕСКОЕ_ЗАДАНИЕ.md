# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Полное наименование системы
Система управления экзаменационными билетами

### 1.2. Краткое наименование системы
СУЭБ

### 1.3. Назначение системы
Веб-приложение для автоматизированного создания, распределения и отслеживания экзаменационных билетов в учебных заведениях.

### 1.4. Основание для разработки
Необходимость автоматизации процесса проведения экзаменов и зачетов в учебных заведениях.

## 2. НАЗНАЧЕНИЕ И ЦЕЛИ СОЗДАНИЯ СИСТЕМЫ

### 2.1. Назначение системы
Система предназначена для:
- Автоматической генерации экзаменационных билетов
- Распределения билетов между курсантами
- Отслеживания процесса выбора билетов
- Формирования статистики по результатам экзаменов

### 2.2. Цели создания системы
- Автоматизация процесса подготовки и проведения экзаменов
- Исключение дублирования билетов
- Обеспечение справедливого распределения билетов
- Упрощение работы преподавателей

## 3. ХАРАКТЕРИСТИКИ ОБЪЕКТОВ АВТОМАТИЗАЦИИ

### 3.1. Краткие сведения об объекте автоматизации
Объектом автоматизации является процесс проведения экзаменов и зачетов в учебных заведениях.

### 3.2. Сведения об условиях эксплуатации
- Операционная система: Windows 7+, Linux, macOS
- Браузер: современный браузер (Chrome, Firefox, Edge, Safari)
- Требования к оборудованию: минимальные (любой современный компьютер)

## 4. ТРЕБОВАНИЯ К СИСТЕМЕ

### 4.1. Требования к системе в целом

#### 4.1.1. Требования к структуре системы
Система состоит из:
- Backend сервера (Node.js, Express)
- Frontend приложения (React)
- Базы данных (SQLite)

#### 4.1.2. Требования к функциям системы
- Управление пользователями (администраторы, преподаватели, курсанты)
- Управление учебными группами
- Управление дисциплинами
- Загрузка вопросов из файлов
- Импорт курсантов из файлов
- Генерация билетов
- Выбор билетов курсантами
- Формирование статистики

#### 4.1.3. Требования к видам обеспечения
- Программное обеспечение: Node.js 14.0.0 или выше
- Техническое обеспечение: стандартный компьютер
- Информационное обеспечение: SQLite база данных

### 4.2. Требования к функциям (подсистемам, задачам)

#### 4.2.1. Подсистема управления пользователями
- Создание, редактирование, удаление пользователей
- Автоматическая генерация логинов и паролей
- Импорт пользователей из файлов

#### 4.2.2. Подсистема управления билетами
- Генерация билетов с уникальными комбинациями вопросов
- Настройка параметров билетов
- Отслеживание выбранных билетов

#### 4.2.3. Подсистема статистики
- Отображение статистики выбора билетов
- История выбора билетов
- Экспорт статистики

### 4.3. Требования к видам обеспечения

#### 4.3.1. Требования к информационному обеспечению
- База данных SQLite
- Формат файлов для импорта: TXT (UTF-8 или ANSI)

#### 4.3.2. Требования к лингвистическому обеспечению
- Интерфейс: русский язык
- Сообщения об ошибках: русский язык

#### 4.3.3. Требования к программному обеспечению
- Node.js 14.0.0 или выше
- Современный веб-браузер

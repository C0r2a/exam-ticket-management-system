## Описание компонентов

### Frontend (client/)
- **React** - библиотека для создания пользовательского интерфейса
- **Components**:
  - `SetupWizard.js` - мастер настройки экзамена
  - `TicketSelection.js` - выбор билетов курсантами
  - `TeacherPanel.js` - панель преподавателя

### Backend (server/)
- **Node.js/Express** - сервер приложения
- **SQLite** - база данных
- **API Endpoints**:
  - `/api/groups` - управление группами
  - `/api/subjects` - управление дисциплинами
  - `/api/users` - управление пользователями
  - `/api/questions` - управление вопросами
  - `/api/tickets` - управление билетами
  - `/api/tickets/statistics` - статистика

### Документация (docs/)
- Техническая документация по ГОСТ
- Руководства пользователя и администратора
- Инструкции по развертыванию

### Скрипты (scripts/)
- Скрипты для запуска приложения
- Утилиты для подготовки к развертыванию

## Файлы конфигурации

### package.json
Основной файл конфигурации проекта, содержит:
- Зависимости проекта
- Скрипты запуска
- Метаданные проекта

### client/package.json
Конфигурация клиентской части:
- Зависимости React
- Настройки сборки
- Прокси для API

## База данных

### server/database.sqlite
SQLite база данных содержит следующие таблицы:
- `users` - пользователи (администраторы, преподаватели, курсанты)
- `groups` - учебные группы
- `subjects` - дисциплины
- `questions` - вопросы
- `tickets` - билеты
- `exam_history` - история выбора билетов
- `config` - конфигурация
- `group_subjects` - связь групп и дисциплин

## Порядок работы с проектом

1. **Разработка:**
   - Изменения в `client/src/` для frontend
   - Изменения в `server/index.js` для backend

2. **Тестирование:**
   - Запуск в режиме разработки: `scripts/start-all.bat`
   - Тестирование на `http://localhost:3000`

3. **Сборка:**
   - Выполнить `npm run build` для сборки клиента
   - Production версия будет в `client/build/`

4. **Развертывание:**
   - Скопировать проект на сервер
   - Запустить `npm start` для production режима
   - Доступ на `http://localhost:8000`

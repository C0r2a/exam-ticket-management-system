# 📦 Развертывание в системе без интернета

Это руководство поможет развернуть приложение на компьютере без доступа к интернету.

## Что нужно подготовить на компьютере с интернетом

### 1. Установить Node.js (если еще не установлен)

Скачайте установщик Node.js с официального сайта:
- **Windows**: https://nodejs.org/ (рекомендуется LTS версия)
- Сохраните установщик для переноса на целевую систему

### 2. Подготовить проект для переноса

#### Вариант A: С копированием node_modules (рекомендуется)

1. **Установите зависимости на компьютере с интернетом:**

```bash
# В корне проекта
npm install

# В папке client
cd client
npm install
cd ..
```

2. **Соберите клиент:**

```bash
npm run build
```

3. **Создайте архив проекта:**

Скопируйте всю папку проекта, включая:
- ✅ `node_modules/` (из корня)
- ✅ `client/node_modules/` 
- ✅ `client/build/` (собранное приложение)
- ✅ Все остальные файлы проекта

**Важно:** Папка `node_modules` может быть большой (около 200-300 МБ). Убедитесь, что у вас достаточно места.

#### Вариант B: Без node_modules (требует интернет на целевой системе)

Если не хотите копировать `node_modules`, можно скопировать только:
- Все исходные файлы проекта
- `package.json` и `package-lock.json` (из корня и из `client/`)
- `client/build/` (если уже собран)

Затем на целевой системе установите зависимости через локальный npm cache (см. раздел ниже).

### 3. Структура для переноса

```
exam/
├── client/
│   ├── build/              # ✅ ОБЯЗАТЕЛЬНО: собранное приложение
│   ├── node_modules/       # ✅ Если используете Вариант A
│   ├── package.json
│   └── package-lock.json
├── server/
│   ├── index.js
│   ├── public/
│   └── uploads/            # (создастся автоматически)
├── node_modules/           # ✅ Если используете Вариант A
├── package.json
├── package-lock.json
├── start-all.bat           # Скрипты запуска
├── start-all.ps1
├── start-server.bat
├── start-client.bat
└── README.md
```

## Развертывание на целевой системе

### Шаг 1: Установка Node.js

1. Скопируйте установщик Node.js на целевую систему
2. Запустите установщик и установите Node.js
3. Проверьте установку:

```bash
node --version
npm --version
```

### Шаг 2: Копирование проекта

1. Скопируйте всю папку проекта на целевую систему
2. Убедитесь, что структура папок сохранена

### Шаг 3: Установка зависимостей

#### Если скопировали node_modules (Вариант A):

Зависимости уже установлены, можно пропустить этот шаг.

**Проверка:**
```bash
# В корне проекта
npm list --depth=0

# В папке client
cd client
npm list --depth=0
cd ..
```

#### Если НЕ скопировали node_modules (Вариант B):

**Вариант B1: Использование npm offline cache**

1. На компьютере с интернетом создайте кэш:

```bash
# В корне проекта
npm cache clean --force
npm install --cache .npm-cache

# В папке client
cd client
npm cache clean --force
npm install --cache .npm-cache
cd ..
```

2. Скопируйте папку `.npm-cache` вместе с проектом

3. На целевой системе установите из кэша:

```bash
# В корне проекта
npm install --cache .npm-cache --offline

# В папке client
cd client
npm install --cache .npm-cache --offline
cd ..
```

**Вариант B2: Использование локального npm registry (требует настройки)**

Если у вас есть локальный npm registry или proxy, настройте его:

```bash
npm config set registry http://your-local-registry:port
npm install
```

### Шаг 4: Сборка клиента (если не скопировали build/)

Если вы не скопировали папку `client/build/`, соберите клиент:

```bash
npm run build
```

Это создаст оптимизированную версию в `client/build/`.

### Шаг 5: Проверка готовности

Убедитесь, что:
- ✅ Node.js установлен
- ✅ Зависимости установлены (или скопированы)
- ✅ Клиент собран (`client/build/` существует)
- ✅ Файлы проекта на месте

## Запуск приложения

### Production режим (рекомендуется для автономной системы)

Запустите только сервер - он будет обслуживать и API, и собранное приложение:

**Windows:**
```bash
# Двойной клик по файлу
start-server.bat

# Или из командной строки
npm start
```

**PowerShell:**
```powershell
.\start-server.bat
```

**Linux/Mac:**
```bash
npm start
```

Приложение будет доступно на: **http://localhost:8000**

### Режим разработки (если нужен)

Если хотите запустить в режиме разработки (с автоперезагрузкой):

**Windows:**
```bash
start-all.bat
```

Это запустит:
- Сервер на порту 8000
- Клиент на порту 3000

## Проверка работы

1. Откройте браузер
2. Перейдите на `http://localhost:8000`
3. Должна открыться панель преподавателя с вкладками "Билеты" и "Статистика"

## Возможные проблемы

### Проблема: "npm: command not found"

**Решение:** Node.js не установлен или не добавлен в PATH. Переустановите Node.js.

### Проблема: "Cannot find module"

**Решение:** Зависимости не установлены. Выполните:
```bash
npm install
cd client && npm install && cd ..
```

### Проблема: "Port 8000 is already in use"

**Решение:** Порт занят другим приложением. Либо:
- Закройте другое приложение
- Или измените порт в `server/index.js` (строка с `const PORT = 8000`)

### Проблема: "ECONNREFUSED"

**Решение:** Сервер не запущен. Запустите сервер командой `npm start`.

## Минимальные требования

- **ОС:** Windows 7+, Linux, macOS
- **Node.js:** версия 14.0.0 или выше (рекомендуется LTS)
- **RAM:** минимум 512 МБ (рекомендуется 1 ГБ)
- **Диск:** минимум 500 МБ свободного места
- **Браузер:** современный браузер (Chrome, Firefox, Edge, Safari)

## Размер проекта

- **Без node_modules:** ~50-100 МБ
- **С node_modules:** ~300-500 МБ
- **Собранное приложение (client/build/):** ~5-10 МБ

## Альтернативный способ: Portable версия

Можно создать полностью портативную версию:

1. Используйте portable версию Node.js (если доступна)
2. Скопируйте весь проект с node_modules
3. Используйте относительные пути в скриптах запуска

## Резервное копирование данных

База данных находится в `server/database.sqlite`. Для резервного копирования:

1. Остановите сервер
2. Скопируйте файл `server/database.sqlite`
3. При необходимости восстановите его обратно

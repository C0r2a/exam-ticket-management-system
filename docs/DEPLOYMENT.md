# Развертывание автономного приложения

Приложение настроено для полностью автономной работы без внешних зависимостей.

## Подготовка к развертыванию

### 1. Установка зависимостей

```bash
npm run install-all
```

### 2. Копирование шрифтов

Шрифты уже скопированы в проект. Если нужно обновить, используйте скрипт:

```bash
node copy-fonts.js
node copy-fonts-to-src.js
```

Или вручную скопируйте из `docs/шрифт/шрифт/` в:
- `client/public/fonts/` (для production)
- `client/src/fonts/` (для разработки)

### 3. Сборка клиента

```bash
npm run build
```

Это создаст оптимизированную версию клиента в папке `client/build/`.

## Запуск приложения

### Режим разработки

**Терминал 1 (Backend):**
```bash
npm run dev
```

**Терминал 2 (Frontend):**
```bash
npm run client
```

Приложение будет доступно на `http://localhost:3000`

### Production режим (автономный)

После сборки клиента запустите только сервер:

```bash
npm start
```

Сервер будет:
- Обслуживать API на `/api/*`
- Обслуживать статические файлы из `client/build/`
- Автоматически перенаправлять все запросы на `index.html` (для React Router)

Приложение будет доступно на `http://localhost:8000`

## Особенности автономной версии

✅ **Нет внешних зависимостей:**
- Локальные шрифты (Montserrat и Magistral)
- Относительные пути для API (`/api` вместо `http://localhost:8000/api`)
- Все ресурсы включены в сборку

✅ **Единый сервер:**
- Backend и Frontend работают на одном порту
- Не требуется отдельный dev-сервер для клиента

✅ **Готово к развертыванию:**
- Можно запустить на любом сервере с Node.js
- Не требует интернет-соединения для работы
- Все данные хранятся локально в SQLite

## Переменные окружения

Для настройки можно использовать переменные окружения:

- `PORT` - порт сервера (по умолчанию 8000)
- `REACT_APP_API_URL` - URL API для клиента (по умолчанию `/api`)

Пример:
```bash
PORT=3000 npm start
```

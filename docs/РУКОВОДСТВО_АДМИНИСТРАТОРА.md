# РУКОВОДСТВО АДМИНИСТРАТОРА

## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Назначение документа
Настоящее руководство предназначено для администраторов системы управления экзаменационными билетами и содержит описание процедур установки, настройки и обслуживания системы.

### 1.2. Краткая характеристика системы
Система управления экзаменационными билетами - веб-приложение на базе Node.js и React для автоматизированного управления экзаменационными билетами.

## 2. ТРЕБОВАНИЯ К СИСТЕМЕ

### 2.1. Аппаратные требования
- Процессор: любой современный процессор
- Оперативная память: минимум 512 МБ (рекомендуется 1 ГБ)
- Свободное место на диске: минимум 500 МБ
- Сетевое подключение: для локальной сети

### 2.2. Программные требования
- Операционная система: Windows 7+, Linux, macOS
- Node.js: версия 14.0.0 или выше
- Браузер: современный браузер (Chrome, Firefox, Edge, Safari)

## 3. УСТАНОВКА СИСТЕМЫ

### 3.1. Установка Node.js
1. Скачайте установщик Node.js с официального сайта: https://nodejs.org/
2. Запустите установщик
3. Следуйте инструкциям установщика
4. Проверьте установку: `node --version`

### 3.2. Установка системы

#### Вариант А: Установка из исходников
1. Скопируйте папку проекта на сервер
2. Откройте терминал в корне проекта
3. Выполните: `npm run install-all`
4. Дождитесь завершения установки зависимостей

#### Вариант Б: Установка готовой версии
1. Скопируйте папку проекта с уже установленными зависимостями
2. Убедитесь, что папка `node_modules` присутствует
3. Убедитесь, что папка `client/build` присутствует (для production)

### 3.3. Сборка клиента (для production)
1. Выполните: `npm run build`
2. Дождитесь завершения сборки
3. Проверьте наличие папки `client/build`

## 4. НАСТРОЙКА СИСТЕМЫ

### 4.1. Конфигурация сервера
По умолчанию сервер работает на порту 8000. Для изменения порта:
1. Откройте файл `server/index.js`
2. Найдите строку: `const PORT = process.env.PORT || 8000;`
3. Измените значение или установите переменную окружения `PORT`

### 4.2. Конфигурация базы данных
База данных SQLite создается автоматически при первом запуске в файле `server/database.sqlite`.

### 4.3. Переменные окружения
Создайте файл `.env` в корне проекта (опционально):
```
PORT=8000
NODE_ENV=production
```

## 5. ЗАПУСК СИСТЕМЫ

### 5.1. Режим разработки
**Windows:**
```bash
scripts\start-all.bat
```

**Linux/Mac:**
```bash
npm run dev    # В одном терминале
npm run client # В другом терминале
```

### 5.2. Production режим
```bash
npm start
```

Система будет доступна на `http://localhost:8000`

### 5.3. Автоматический запуск при загрузке системы

#### Windows:
1. Создайте ярлык для `scripts\start-server.bat`
2. Поместите ярлык в папку автозагрузки:
   - `Win+R` → `shell:startup`
   - Скопируйте ярлык в эту папку

#### Linux (systemd):
Создайте файл `/etc/systemd/system/exam-tickets.service`:
```ini
[Unit]
Description=Exam Tickets System
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/path/to/exam
ExecStart=/usr/bin/node server/index.js
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем:
```bash
sudo systemctl enable exam-tickets
sudo systemctl start exam-tickets
```

## 6. ОБСЛУЖИВАНИЕ СИСТЕМЫ

### 6.1. Резервное копирование
Регулярно создавайте резервные копии:
- `server/database.sqlite` - база данных
- `server/uploads/` - загруженные файлы

### 6.2. Очистка данных
Для полного сброса данных:
1. Остановите сервер
2. Удалите файл `server/database.sqlite`
3. Очистите папку `server/uploads/`
4. Запустите сервер (база данных создастся автоматически)

### 6.3. Обновление системы
1. Остановите сервер
2. Создайте резервную копию базы данных
3. Обновите файлы проекта
4. Выполните: `npm run install-all`
5. Выполните: `npm run build` (для production)
6. Запустите сервер

### 6.4. Мониторинг
Проверяйте логи сервера для выявления проблем. Логи выводятся в консоль.

## 7. БЕЗОПАСНОСТЬ

### 7.1. Защита данных
- Система работает только в локальной сети
- Данные хранятся локально
- Нет передачи данных в интернет

### 7.2. Рекомендации
- Используйте систему только в защищенной локальной сети
- Регулярно создавайте резервные копии
- Ограничьте физический доступ к серверу

## 8. РЕШЕНИЕ ПРОБЛЕМ

### 8.1. Проблема: Порт занят
**Решение:**
1. Найдите процесс, использующий порт: `netstat -ano | findstr :8000` (Windows)
2. Завершите процесс или измените порт в настройках

### 8.2. Проблема: Ошибки базы данных
**Решение:**
1. Проверьте права доступа к файлу базы данных
2. Проверьте свободное место на диске
3. При необходимости восстановите из резервной копии

### 8.3. Проблема: Зависимости не устанавливаются
**Решение:**
1. Проверьте подключение к интернету
2. Очистите кэш npm: `npm cache clean --force`
3. Попробуйте установить зависимости заново

### 8.4. Проблема: Клиент не собирается
**Решение:**
1. Проверьте версию Node.js (должна быть 14+)
2. Удалите папку `node_modules` и `package-lock.json`
3. Выполните установку заново

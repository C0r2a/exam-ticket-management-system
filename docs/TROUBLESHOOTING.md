# Решение проблем с подключением к серверу

## Проблема: Ошибка подключения к серверу

### Шаг 1: Проверьте, запущен ли сервер

Откройте терминал в корневой папке проекта и выполните:

```bash
npm start
```

Или:

```bash
cd server
node index.js
```

Вы должны увидеть сообщение: `Сервер запущен на порту 8000`

### Шаг 2: Проверьте, не занят ли порт 8000

**Windows:**
```powershell
netstat -ano | findstr :8000
```

**Если порт занят:**
1. Найдите PID процесса
2. Завершите процесс: `taskkill /PID <PID> /F`
3. Или измените порт в `server/index.js` (строка 11)

### Шаг 3: Проверьте настройки URL

Убедитесь, что в файлах клиента используется правильный URL:

- `client/src/components/SetupWizard.js` - использует `process.env.REACT_APP_API_URL || '/api'`
- `client/src/components/TicketSelection.js` - использует `process.env.REACT_APP_API_URL || '/api'`
- `client/src/components/TeacherPanel.js` - использует `process.env.REACT_APP_API_URL || '/api'`

В режиме разработки используется proxy из `client/package.json`, в production - относительные пути `/api`

### Шаг 4: Проверьте proxy в package.json

В файле `client/package.json` должна быть строка:
```json
"proxy": "http://localhost:8000"
```

### Шаг 5: Проверьте CORS на сервере

В файле `server/index.js` должна быть строка:
```javascript
app.use(cors());
```

### Шаг 6: Запустите клиент и сервер в разных терминалах

**Терминал 1 (Backend):**
```bash
npm start
# или
npm run dev
```

**Терминал 2 (Frontend):**
```bash
npm run client
```

### Шаг 7: Проверьте консоль браузера

Откройте DevTools (F12) и проверьте вкладку Console на наличие ошибок.

### Шаг 8: Проверьте Network в DevTools

1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Попробуйте выполнить действие, которое вызывает ошибку
4. Проверьте статус запросов (должны быть 200 или другие успешные коды)

## Частые ошибки

### "Network Error" или "ERR_CONNECTION_REFUSED"
- **Причина:** Сервер не запущен
- **Решение:** Запустите сервер командой `npm start`

### "CORS policy" ошибка
- **Причина:** Проблемы с CORS
- **Решение:** Убедитесь, что в `server/index.js` есть `app.use(cors())`

### "404 Not Found"
- **Причина:** Неправильный URL или endpoint не существует
- **Решение:** Проверьте URL в компонентах и убедитесь, что endpoint существует в `server/index.js`

### Порт уже занят
- **Причина:** Другой процесс использует порт 8000
- **Решение:** 
  1. Найдите и завершите процесс: `netstat -ano | findstr :8000`
  2. Или измените порт в `server/index.js`

## Быстрая проверка

Выполните в PowerShell:

```powershell
# Проверка порта
netstat -ano | findstr :8000

# Проверка процесса Node.js
Get-Process -Name node -ErrorAction SilentlyContinue

# Тест подключения к серверу
Invoke-WebRequest -Uri "http://localhost:8000/api/auth/login" -Method POST -ContentType "application/json" -Body '{"username":"test","password":"test"}'
```

Если последняя команда возвращает ошибку, сервер не запущен или не отвечает.

## Автоматический запуск при перезагрузке компьютера

### Проблема: После перезагрузки компьютера сервер не запускается автоматически

**Решение:** Используйте готовые скрипты для запуска или настройте автозапуск.

### Вариант 1: Использование готовых скриптов (рекомендуется)

В корневой папке проекта есть готовые скрипты:

#### Для Windows (BAT файлы):

1. **`start-all.bat`** - Запускает сервер и клиент одновременно
   - Двойной клик по файлу
   - Сервер откроется в отдельном окне
   - Клиент откроется в текущем окне

2. **`start-server.bat`** - Запускает только сервер
   - Двойной клик по файлу
   - Полезно, если клиент уже запущен

3. **`start-client.bat`** - Запускает только клиент
   - Двойной клик по файлу
   - Полезно, если сервер уже запущен

#### Для PowerShell:

1. **`start-all.ps1`** - Запускает сервер и клиент
   ```powershell
   .\start-all.ps1
   ```

### Вариант 2: Настройка автозапуска через планировщик задач Windows

1. Откройте **Планировщик задач** (Task Scheduler)
2. Создайте новую задачу:
   - **Имя:** "Экзаменационные билеты - Сервер"
   - **Триггер:** При входе в систему
   - **Действие:** Запустить программу
   - **Программа:** `C:\Windows\System32\cmd.exe`
   - **Аргументы:** `/c "cd /d C:\Users\blank\Documents\exam && npm start"`
   - **Рабочая папка:** `C:\Users\blank\Documents\exam`
   - **Параметры:** 
     - ✅ Запускать с наивысшими правами (если нужно)
     - ✅ Выполнять для всех пользователей (опционально)

3. Повторите для клиента (если нужно):
   - **Имя:** "Экзаменационные билеты - Клиент"
   - **Аргументы:** `/c "cd /d C:\Users\blank\Documents\exam && npm run client"`

**Важно:** Замените `C:\Users\blank\Documents\exam` на путь к вашему проекту!

### Вариант 3: Создание ярлыка на рабочем столе

1. Правой кнопкой мыши на рабочем столе → **Создать → Ярлык**
2. Укажите путь к `start-all.bat`:
   ```
   C:\Users\blank\Documents\exam\start-all.bat
   ```
3. Назовите ярлык: "Запустить экзаменационные билеты"
4. Двойной клик по ярлыку запустит приложение

### Вариант 4: Добавление в автозагрузку через папку автозагрузки

1. Нажмите `Win + R`
2. Введите: `shell:startup`
3. Создайте ярлык для `start-all.bat` в этой папке
4. При каждом входе в Windows приложение будет запускаться автоматически

### Быстрая проверка после запуска

После запуска проверьте:

```powershell
# Проверка сервера
Invoke-WebRequest -Uri "http://localhost:8000/api/groups" -Method GET

# Проверка портов
netstat -ano | findstr ":8000"
netstat -ano | findstr ":3000"
```

Если команды возвращают успешный результат, всё работает правильно!

### Решение проблемы "ECONNREFUSED"

Если вы видите ошибку `ECONNREFUSED` или `Proxy error: Could not proxy request`:

1. **Проверьте, запущен ли сервер:**
   ```powershell
   netstat -ano | findstr :8000
   ```
   Если ничего не выводится, сервер не запущен.

2. **Запустите сервер:**
   - Двойной клик по `start-server.bat`
   - Или в терминале: `npm start`

3. **Проверьте, что сервер отвечает:**
   ```powershell
   Invoke-WebRequest -Uri "http://localhost:8000/api/groups" -Method GET
   ```

4. **Если порт занят другим процессом:**
   ```powershell
   # Найти процесс
   netstat -ano | findstr :8000
   # Завершить процесс (замените PID на номер из предыдущей команды)
   taskkill /PID <PID> /F
   ```

### Полезные команды

```powershell
# Остановить все процессы Node.js
Get-Process -Name node -ErrorAction SilentlyContinue | Stop-Process -Force

# Проверить, какие порты заняты
netstat -ano | findstr "LISTENING"

# Запустить только сервер
npm start

# Запустить только клиент
npm run client

# Запустить оба (в разных терминалах)
start-all.bat
```

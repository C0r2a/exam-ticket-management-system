# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ

## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Назначение документа
Настоящее руководство предназначено для пользователей системы управления экзаменационными билетами и содержит описание процедур работы с системой.

### 1.2. Краткая характеристика системы
Система управления экзаменационными билетами - веб-приложение для автоматизированного создания, распределения и отслеживания экзаменационных билетов.

### 1.3. Состав документа
- Описание интерфейса
- Процедуры работы с системой
- Описание функций
- Решение типовых проблем

## 2. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ

### 2.1. Назначение системы
Система предназначена для автоматизации процесса проведения экзаменов и зачетов.

### 2.2. Условия применения
- Наличие современного веб-браузера
- Подключение к локальной сети (для доступа к серверу)
- Права доступа, предоставленные администратором

## 3. ПОДГОТОВКА К РАБОТЕ

### 3.1. Требования к системе
- Операционная система: Windows 7+, Linux, macOS
- Браузер: Chrome, Firefox, Edge, Safari (последние версии)
- JavaScript должен быть включен

### 3.2. Запуск системы
1. Откройте браузер
2. Перейдите по адресу: `http://localhost:3000` (для режима разработки) или `http://localhost:8000` (для production)
3. Дождитесь загрузки интерфейса

## 4. ОПИСАНИЕ ИНТЕРФЕЙСА

### 4.1. Главное меню
Главное меню содержит следующие режимы:
- **Настройка** - подготовка экзамена
- **Сдача** - выбор билетов курсантами
- **Статистика** - просмотр статистики (на порту 8000)

### 4.2. Режим "Настройка"
Мастер настройки состоит из 7 шагов:
1. Ввод данных дисциплины
2. Загрузка вопросов
3. Ввод данных группы
4. Добавление курсантов
5. Конфигурация билетов
6. Генерация билетов
7. Готово

## 5. ПРОЦЕДУРЫ РАБОТЫ

### 5.1. Подготовка экзамена (для преподавателя)

#### Шаг 1: Ввод данных дисциплины
1. Введите название дисциплины
2. Выберите тип (Экзамен/Зачет)
3. Нажмите "Продолжить"

#### Шаг 2: Загрузка вопросов
1. Подготовьте TXT файл с вопросами (один вопрос на строку)
2. Нажмите "Загрузить вопросы из TXT файла"
3. Выберите файл
4. Дождитесь загрузки
5. Проверьте количество загруженных вопросов
6. Нажмите "Продолжить"

#### Шаг 3: Ввод данных группы
1. Введите название учебной группы
2. Нажмите "Продолжить"

#### Шаг 4: Добавление курсантов
**Вариант А: Ручное добавление**
1. Введите ФИО курсанта
2. Нажмите "Добавить"

**Вариант Б: Импорт из файла**
1. Подготовьте TXT файл с ФИО курсантов (одно ФИО на строку)
2. Нажмите "Импорт курсантов из TXT файла"
3. Выберите файл
4. Дождитесь импорта
5. Проверьте список курсантов

После добавления всех курсантов нажмите "Продолжить"

#### Шаг 5: Конфигурация билетов
1. Установите количество билетов (1-100)
2. Установите количество теоретических вопросов (1-20)
3. При необходимости включите практические задания
4. При необходимости включите разделы вопросов
5. Нажмите "Сохранить и продолжить"

#### Шаг 6: Генерация билетов
1. Проверьте все параметры
2. Нажмите "Сгенерировать билеты"
3. Дождитесь завершения генерации
4. Нажмите "Продолжить"

#### Шаг 7: Готово
1. Проверьте итоговую информацию
2. Нажмите "Начать экзамен"

### 5.2. Выбор билета (для курсанта)

1. Выберите курсанта из выпадающего списка
2. Выберите билет из доступных карточек
3. В модальном окне просмотрите содержимое билета
4. Нажмите "Начать подготовку"

### 5.3. Просмотр статистики

1. Откройте `http://localhost:8000`
2. Выберите учебную группу
3. Выберите дисциплину
4. Перейдите на вкладку "Статистика"
5. Просмотрите статистику выбора билетов

## 6. ФОРМАТЫ ФАЙЛОВ

### 6.1. Файл с вопросами
Формат: TXT, кодировка UTF-8 или ANSI
Структура: один вопрос на строку

Пример:
```
Что такое переменная?
Как объявить функцию?
Что такое массив?
```

### 6.2. Файл с курсантами
Формат: TXT, кодировка UTF-8 или ANSI
Структура: одно ФИО на строку

Пример:
```
Иванов Иван Иванович
Петров Петр Петрович
Сидоров Сидор Сидорович
```

## 7. РЕШЕНИЕ ТИПОВЫХ ПРОБЛЕМ

### 7.1. Проблема: "Билеты еще не сгенерированы"
**Решение:** Перейдите в режим "Настройка" и выполните генерацию билетов

### 7.2. Проблема: "Учебная группа не найдена"
**Решение:** Проверьте, что настройка завершена полностью. При необходимости начните настройку заново.

### 7.3. Проблема: "Ошибка загрузки файла"
**Решение:** 
- Проверьте формат файла (должен быть .txt)
- Проверьте кодировку файла (должна быть UTF-8 или ANSI)
- Проверьте, что файл не пустой

### 7.4. Проблема: "ECONNREFUSED"
**Решение:** Убедитесь, что сервер запущен. Используйте скрипт `scripts/start-all.bat` для запуска.

## 8. ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ

### 8.1. Сброс данных
В режиме "Настройка" доступна кнопка "Сбросить все" для полного сброса всех данных.

### 8.2. Завершение экзамена
После того, как все курсанты выбрали билеты, доступна кнопка "Закончить зачет" для завершения экзамена.
